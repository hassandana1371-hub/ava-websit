# ابزار کمپین آوا — نسخهٔ ۱

این ابزار پیش‌نویس محتوا و لینک کمپین تولید می‌کند. ربات بازدید، کاربر مصنوعی، ارسال پیام یا اتصال حساب شبکهٔ اجتماعی ندارد. تولید خروجی به معنی انتشار یا جذب بازدید نیست.

اجرای ساده با Python 3، بدون وابستگی جانبی:

```sh
python3 tools/marketing_pack.py
```

خروجی در marketing/generated قرار می‌گیرد: posts-fa.md برای خواندن/کپی و campaign.json برای استفاده در برنامهٔ انتشار بعدی. نمونهٔ آماده شامل هشت پیش‌نویس در روزهای نسبی ۱ تا ۱۵ است. این روزها تقویم پیشنهادی‌اند؛ زمان‌بندی یا انتشار خودکار فعال نشده است.

ورودی پیش‌فرض، محتوای نمونهٔ مخزن است و محتوای زندهٔ دیتابیس شما نیست. برای استفاده از محتوای به‌روز، از پنل سایت خروجی JSON محتوا بگیرید و به ابزار بدهید:

```sh
python3 tools/marketing_pack.py --input ava-content-backup.json --channel telegram --campaign ava-buy-guide --output marketing/telegram
python3 tools/marketing_pack.py --input ava-content-backup.json --channel instagram --campaign ava-buy-guide --output marketing/instagram
python3 tools/marketing_pack.py --input ava-content-backup.json --channel whatsapp --campaign ava-buy-guide --output marketing/whatsapp
```

پیش‌نویس‌ها فقط از محصولات و خدمات منتشرشده ساخته می‌شوند؛ محصولات دستهٔ پنهان و پیش‌نویس‌ها معرفی نمی‌شوند. ورودی تغییر نمی‌کند. مبلغ قدیمی محصول به‌عنوان قیمت امروز وارد قالب تبلیغ نمی‌شود؛ مشخصات و شرایط فعلی هر متن و تصویر همان محصول را پیش از انتشار بررسی کنید.

برای اینستاگرام، لینک کپشن معمولاً کلیک‌پذیر نیست؛ tracked_link را در لینک بیو یا استوری قرار دهید. قالب instagram به لینک بیو/استوری اشاره می‌کند. متن تلگرام برای کانال متعلق به خودتان و متن واتساپ برای وضعیت یا مخاطبان علاقه‌مند قابل استفاده است. هیچ پیام یا پستی از طرف ابزار فرستاده نمی‌شود.

لینک‌ها دارای utm_source، utm_medium، utm_campaign و utm_content هستند. این برچسب‌ها کاربر ایجاد نمی‌کنند و نیاز به ابزار تحلیلِ پشتیبان UTM دارند؛ آمار تجمیعی فعلی سایت گزارش تفکیک کمپین ندارد. هیچ تعداد کلیک، مشتری یا رتبه‌ای ساخته یا تضمین نشده است.

برای انتشار خودکار بعدی، شبکهٔ اجتماعی، آدرس حساب/کانال و اتصال معتبر با اجازهٔ انتشار لازم است؛ در این جلسه چنین اتصالی موجود نیست. محدودیت‌ها و قابلیت‌های API هر شبکه باید برای همان حساب بررسی شود. این ابزار بدون تغییر سایت، دیتابیس، سامانهٔ انبار یا تنظیمات سرور اجرا می‌شود.
