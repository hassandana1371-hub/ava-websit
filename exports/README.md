# خروجی‌های سایت آوا

نسخهٔ جدید: **۱۹**؛ پخش خودکار پیوسته پس از حرکت دستی، حذف پلی پایین هیرو، فلش بدون کادر و بارگذاری عکس تا ۵ مگابایت.

- [دریافت ZIP نسخهٔ ۱۹](https://github.com/hassandana1371-hub/ava-websit/raw/refs/heads/main/exports/ava-site-v19-backup.zip)
- [فایل HTML کامل نسخهٔ ۱۹](ava-site-v19-backup.html)
- [پیش‌نمایش هیرو](ava-v19-hero-preview.png)

ZIP را باز کنید و فایل `ava-site.html` را در مرورگر اجرا کنید. عکس‌ها، فونت‌ها و موشن‌لوگو داخل همان فایل هستند و نصب یا اینترنت لازم نیست.

پخش خودکار بعد از کلیک روی فلش و نشانگر یا کشیدن موس و انگشت ادامه می‌یابد؛ دکمهٔ پلی ندارد. عکس‌های معمولی هر دو ثانیه عوض می‌شوند و موشن‌لوگو همان دو دور کامل را دارد. فلش‌ها در hover و کلیک کادر مستطیلی ندارند.

همهٔ ورودی‌های عکس تا ۵ مگابایت را می‌پذیرند؛ عکس‌های بزرگ برای وب بهینه می‌شوند. PDF محصول همچنان تا ۲ مگابایت است. برای حفظ تغییرات پنل، از بخش پشتیبان خروجی کامل HTML بگیرید.

[نسخهٔ ۱۸](ava-site-v18-backup.zip)، [نسخهٔ ۱۷](ava-site-v17-backup.zip) و [نسخهٔ ۱۵](ava-site-v15-backup.zip) هم نگهداری شده‌اند.
