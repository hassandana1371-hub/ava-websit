# خروجی کامل سایت آوا، نسخهٔ ۱۵

فایل `ava-site-v15-backup.html` شامل سایت، پنل، تصاویر و فونت است. عکس‌های هیرو هر دو ثانیه جابه‌جا می‌شوند.

برای دریافت از گیت‌هاب، فایل ZIP را باز کنید و دکمهٔ **Download raw file** را بزنید. سپس ZIP را از حالت فشرده خارج کنید و فایل `ava-site.html` را با مرورگر باز کنید.

این خروجی دقیقاً نسخهٔ ۱۵ درخواست‌شده است. موشن‌لوگوی نسخهٔ ۱۶ در آن نیست.
