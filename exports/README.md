# خروجی‌های سایت آوا

نسخهٔ جدید: **۱۸**؛ هیرو با کشیدن موس یا انگشت، فلش‌های محو و نشانگر پایین، ورود دیزاولف به صفحات، فونت استعداد، تصاویر جدید و PDF قابل بارگذاری از پنل.

- [دریافت ZIP نسخهٔ ۱۸](https://github.com/hassandana1371-hub/ava-websit/raw/refs/heads/main/exports/ava-site-v18-backup.zip)
- [فایل HTML کامل نسخهٔ ۱۸](ava-site-v18-backup.html)
- [پیش‌نمایش هیرو و کنترل‌ها](ava-v18-hero-preview.png)
- [پیش‌نمایش صفحهٔ محصول](ava-v18-product-preview.png)
- [پیش‌نمایش کارت‌ها](ava-v18-cards-preview.png)

ZIP را باز کنید و فایل `ava-site.html` را با مرورگر اجرا کنید. عکس‌ها، فونت‌ها و موشن‌لوگو داخل فایل هستند؛ نصب یا اینترنت لازم نیست.

بعد از انتخاب دستی اسلاید، پخش خودکار متوقف می‌شود؛ دکمهٔ پخش در پایین هیرو آن را دوباره فعال می‌کند. در حالت خودکار، موشن‌لوگو دو دور کامل و سپس عکس‌ها با فاصلهٔ دو ثانیه پخش می‌شوند.

برای فایل محصول: منو ← مدیریت سایت ← محصولات ← ویرایش محصول ← فایل‌های این محصول. PDF را بارگذاری کنید، نام نمایشی آن را تعیین کنید و ذخیره کنید؛ همان فایل در تب «فایل‌ها و دانلودها» نمایش داده می‌شود. برای نگهداری تغییرات پنل، از بخش پشتیبان، خروجی کامل HTML بگیرید.

۲۱ محصول و قیمت‌های قبلی حفظ شده‌اند؛ تصاویر نمایشی مطابق اطلاعات بستهٔ جدید با برچسب مشخص‌اند. [نسخهٔ ۱۷](ava-site-v17-backup.zip) و [نسخهٔ ۱۵](ava-site-v15-backup.zip) نیز برای مراجعه باقی مانده‌اند.
