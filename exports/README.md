# خروجی‌های سایت آوا

نسخهٔ جدید: **۱۷**، شامل هدر جمع‌وجور، هیروی بزرگ، موشن‌لوگوی دو دور، بنر مستقل دسته‌ها و ۲۱ محصول با عکس و قیمت‌های فایل ارسالی.

- [دریافت ZIP نسخهٔ ۱۷](https://github.com/hassandana1371-hub/ava-websit/raw/refs/heads/main/exports/ava-site-v17-backup.zip)
- [فایل HTML کامل نسخهٔ ۱۷](ava-site-v17-backup.html)
- [پیش‌نمایش بنر دسته](ava-v17-catalogue-preview.png)
- [پیش‌نمایش کارت‌های محصولات](ava-v17-products-preview.png)

فایل ZIP را دریافت و باز کنید؛ فایل `ava-site.html` داخل آن با مرورگر اجرا می‌شود و نصب یا اینترنت لازم ندارد. فونت، تصاویر و موشن‌لوگو داخل فایل هستند.

۱۴ قیمت، قیمت مرجع هر ماژول به تومان هستند و ۷ مدل «استعلام قیمت» دارند. قیمت‌ها از فایل کاربر وارد شده‌اند و قیمت نهایی فروش محسوب نمی‌شوند. نوع قیمت، مبلغ و مبنای آن از پنل قابل تغییر است.

برای تغییر عکس بنر: منو ← مدیریت سایت ← محصولات ← مدیریت دسته‌بندی‌ها ← ویرایش دسته. برای تغییر عکس یا قیمت محصول: مدیریت سایت ← محصولات ← ویرایش محصول. پس از تغییرات در پنل، از بخش پشتیبان خروجی کامل HTML بگیرید تا تغییرات همراه فایل بمانند.

خروجی قدیمی [نسخهٔ ۱۵](ava-site-v15-backup.zip) نیز نگهداری شده است.
