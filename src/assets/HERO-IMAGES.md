# تصاویر پیش‌نمایش هیرو

این چهار تصویر، تصویرسازی مفهومی تولیدشده با ابزار تصویرساز در همین جلسه هستند؛ عکس مستند محصول، موجودی، نمایندگی یا پروژهٔ اجراشدهٔ آوا نیستند. در نسخهٔ ۱۴ هیرو فقط تصویری است و روی آن نوشته یا برچسب نمایش داده نمی‌شود؛ مفهومی بودن عکس‌ها در این سند ثبت شده است.

درخواست اصلی یافتن عکس‌های واقعی سازندگان بود. جست‌وجوی Bing و دسترسی به صفحات LEDWorld، LEDSINO و Unilumin در این محیط با پاسخ 403 پراکسی محدود شد. صفحهٔ مرجع NovaStar قابل خواندن بود، اما تصاویر مناسب این چهار نوع نمایشگر از آن انتخاب نشدند. تصاویر از سایت دیگری برداشته نشده‌اند.

| فایل | موضوع |
| --- | --- |
| `hero-wall.webp` | نمایشگر LED بزرگ در سالن |
| `hero-film.webp` | فیلم LED شفاف نصب‌شده روی شیشه |
| `hero-flex.webp` | نمایشگر منعطف با نصب منحنی |
| `hero-floor.webp` | کف LED |

ابعاد هر تصویر ۱۹۱۶ × ۸۲۱ پیکسل است. نسخه‌های PNG اصلی در پوشهٔ `/workspace/generated_images/` باقی مانده‌اند. نسخه‌های WebP با حفظ ابعاد و فقط برای کاهش حجم فایل آماده شده‌اند. `build.py` تصاویر را در اسکریپت JSON مستقل `ava-hero-images` جاسازی می‌کند؛ پنل، پشتیبان و خروجی HTML برای این تصاویر به اینترنت نیاز ندارند و دادهٔ تصویرهای پیش‌فرض بی‌دلیل در localStorage تکرار نمی‌شود.

مسیر تعویض عکس: دکمهٔ منو ← مدیریت سایت ← هیرو / تصویر اصلی ← اسلاید موردنظر ← انتخاب عکس این اسلاید ← ذخیرهٔ اسلایدر. حداکثر حجم هر تصویر بارگذاری‌شده ۵ مگابایت است؛ خطای کمبود فضای مرورگر اطلاعات ذخیره‌شده و فرم را حفظ می‌کند.
